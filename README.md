# Quicklook MacOs plugin for scad files

> based on https://github.com/3bnz/preview-scad
>  & updated to work on MacOs 15.7

## HowToUse
* Build project using XCode
* copy app to Application folder
* run app from Application folder
* clean cache `qlmanage -r` & `qlmanage -r cache`
* restart Finder `killall Finder`
